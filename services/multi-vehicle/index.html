Multi-Vehicle Questions

Can I split the visit with a neighbour?

Yes — same address or adjoining driveways, same visit window. First vehicle pays $139, each additional pays the $79/$159 rate regardless of whose it is.

What's the math for a two-car household?

Two on-rim swaps: $139 + $79 = $218 — $109 per car, versus $278 booked as two separate visits. Off-rim pair: $229 + $159 = $388.

Is there a limit?

Up to four vehicles per residential visit keeps the window honest. Five or more is fleet territory — better pricing, scheduled program.

Do storage and balancing get the same treatment?

Storage is per set ($119/season each). Balancing added to any vehicle on the visit is the standard $99. Everything lands on the same visit and invoice.
